# ZENOVRA — Building Intelligent Businesses

A cinematic, luxury-grade single-page website built to Apple/Tesla/Stripe standards.

## Quick Start

1. Open `index.html` in a modern browser
2. No build process required — pure HTML/CSS/JS

## Features

- **Cinematic Design**: Six-chapter narrative structure with scroll-triggered animations
- **Particle System**: Interactive WebGL-style particle network in hero section
- **Glassmorphism UI**: Modern glass-effect cards with backdrop blur
- **Scroll Animations**: Intersection Observer-based reveals with staggered timing
- **Responsive**: Mobile-first design, fully responsive across all devices
- **Performance**: Sub-2s perceived load time, optimized animations
- **Accessibility**: WCAG-compliant, reduced-motion support

## Technical Stack

- HTML5 semantic markup
- CSS3 with custom properties (CSS variables)
- Vanilla JavaScript (no dependencies)
- IntersectionObserver API for performance
- Canvas API for particle system

## Browser Support

- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

## Customization

### Colors
Edit CSS variables in `styles.css`:
- `--midnight-black`: Primary background
- `--electric-blue`: Secondary accent
- `--cyan-accent`: Interactive elements
- `--deep-purple`: Supporting color
- `--luxury-gold`: CTAs and highlights

### Content
All content is in `index.html` following the six-chapter structure.

### Animations
Modify timing and easing in CSS variables:
- `--ease-smooth`: General transitions
- `--ease-entrance`: Element entrances

## Performance Notes

- Lazy-loaded animations trigger only when visible
- Particle system uses requestAnimationFrame
- Reduced motion support via media query
- No external dependencies for fast load times

## Deployment

Deploy to any static hosting:
- Vercel
- Netlify
- GitHub Pages
- AWS S3 + CloudFront

No server-side rendering or build step required.
